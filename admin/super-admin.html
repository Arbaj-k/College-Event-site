Security model

Super Admin access is verified against the profiles table. College Admin event permissions are enforced by PostgreSQL Row Level Security.

There is no public Super Admin registration or public Super Admin link.

Event retention

Events are copied to a private archive once their end date (or start date when no end date exists) is at least seven days in the past. Original event records remain unchanged.

Schedule the database archive function daily using Supabase Cron.
